### [lockbox](https://github.com/NishuGoel/lockbox)

A personal, end-to-end encrypted password manager in the spirit of 1Password: a macOS desktop app, a CLI, a browser extension for Chrome and Dia, and a self-hosted sync server that only ever sees ciphertext. Passkeys, 2FA codes, quick access from anywhere, and anti-phishing autofill that only fills on the right site.

<p class="meta">Rust · Tauri · pre-alpha</p>

### [lambda-server-timing](https://www.npmjs.com/package/lambda-server-timing)

Enables Lambdas to return responses with a Server-Timing header, passing request-specific timings from the backend to the browser.

Server-Timing lets a server communicate performance metrics about the request-response cycle to the user agent, and gives applications a JavaScript interface to collect, process and act on them.

<p class="meta">Node.js · AWS Lambda · npm</p>

### [svelte-i18next](https://www.npmjs.com/package/svelte-i18next)

Wraps an i18next instance in a Svelte store that observes [i18next events](https://github.com/NishuGoel/svelte-i18next/blob/main/src/translation-store.ts#L23), so your Svelte components re-render when the language changes or a new resource is loaded.

<p class="meta">Svelte · i18next · npm</p>
